# Current European campaign keyword and ad files

Snapshot after the changes applied on **3 November 2026** to the 18 campaigns launched on 2 November. These files use the same Google Ads Editor column names and keyword/ad row layout as the older campaign files in this folder. Additional headline and description columns retain the full updated ads.

Each `ScanInbox-<LANG>-24-Keywords-and-Ads.csv` contains **24 keywords and three responsive search ads**:

- Six native-language terms and six English terms, each in Exact and Phrase match: 12 native keyword rows and 12 English keyword rows per campaign.
- Eight keywords per ad group: Printer SMTP, Scan-to-Email Setup, and Microsoft 365 Alternative.
- EUR0.90 maximum CPC for every keyword.
- Each ad has 15 headlines and four descriptions. The prelaunch headline remains pinned first, and the final URL uses the campaign's language.

Across all 18 files: **432 keyword rows and 54 ad rows**. This is the actual focused set applied to these campaigns, not the larger October research drafts. The older 191–202-keyword files remain historical drafts and should not be mistaken for the live keyword inventory.

## Import convention and live settings

As in the existing Ireland and Latvia files, **Campaign status is deliberately Paused for import review**. The live campaigns are enabled. Posting the CSV's status field to an existing campaign could pause it; review or exclude that field before posting. These files are documentation and reviewable Editor inputs, not instructions to reimport all rows blindly or create duplicate campaigns.

The live budget is **EUR50 total per campaign for 2 November–2 December 2026**, EUR900 combined, not EUR50 per day. Budget, targeting and end dates are not changed by publishing these files. Countries retain their own native campaign language setting; English keywords do not mean the campaign language setting was changed to English.

Exact Google Ads web bulk-upload files, application results, callouts/sitelinks and the unresolved GTM access limitation are recorded in [the 3 November update](../updates/2026-11-03/README.md). The original [2 November launch](../launches/2026-11-02/README.md) is preserved separately.
